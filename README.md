# The Influence of Salience on Free Recall Accuracy with Words

## Overview
Senior thesis research investigating how visual salience affects free recall 
accuracy in word-based memory tasks.

## Research Questions
How does the salience of a word influence its likelihood of being freely recalled?

## Methods
- Experimental design built in PsychoPy and JavaScript
- Study deployed and data collected via Pavlovia
- Participants recruited independently
- Data analyzed using JASP and RStudio

## Key Findings
Produced statistically significant findings on the relationship between 
salience and free recall accuracy.

## Tools & Languages
Python | JavaScript | PsychoPy | Pavlovia | JASP | RStudio
